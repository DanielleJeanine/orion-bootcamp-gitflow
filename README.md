# 🚀 Orion Bootcamp | Git, GitHub e Git Flow

Repositório dedicado às atividades práticas do treinamento de **Git, GitHub e Git Flow** do **Orion Bootcamp**.

O objetivo é desenvolver habilidades de controle de versão e organização do desenvolvimento, explorando um fluxo de trabalho utilizado em projetos colaborativos.

## 🎯 Objetivos

- Praticar o versionamento de arquivos com Git.
- Utilizar o GitHub para hospedar e acompanhar alterações no código.
- Criar e gerenciar branches.
- Trabalhar com commits, merges e pull requests.
- Compreender a organização de branches proposta pelo Git Flow.


## 🌿 Estrutura de branches


| Branch | Finalidade |
| --- | --- |
| `production` | Manter as versões estáveis do projeto. |
| `develop` | Integrar as funcionalidades em desenvolvimento. |
| `feature/*` | Desenvolver novas funcionalidades. |
| `stage/*` | Preparar testes de qualidade. |
| `hotfix/*` | Corrigir problemas urgentes da versão estável. |


## 📚 Sobre este repositório

Este é um ambiente de aprendizado. Os arquivos e o histórico de commits serão atualizados conforme o avanço das atividades do treinamento.
